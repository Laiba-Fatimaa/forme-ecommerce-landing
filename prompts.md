# AI Prompts and Outcomes

## Prompt 1 — Planning
**Prompt:**  
"Act as a UI/UX designer. Plan a responsive one-page ecommerce landing page for a fictional minimal lifestyle store. Include a hero with a full-width background image, centered headline, a two-line description and CTA, followed by category filters and a product grid. Suggest sections, audience, colors, typography, and simple interactions. Keep the scope suitable for a beginner student project."

**Outcome:**  
The project was scoped as a one-page storefront with a hero, brand introduction, filterable product collection, feature banner, newsletter area, and footer. A warm neutral palette and editorial typography were selected.

## Prompt 2 — Implementation
**Prompt:**  
"Build a beginner-friendly ecommerce landing page using only HTML, CSS, and vanilla JavaScript. It must be responsive and include a sticky navigation bar, a full-screen photographic hero with centered text, product cards, working category filters, a demo add-to-cart counter, a newsletter confirmation, and a mobile menu. Use semantic HTML, accessible labels, and comments where useful. Do not add a backend or payment processing."

**Outcome:**  
The website was implemented as three files: index.html, style.css, and script.js. JavaScript handles category filtering, demo bag totals, mobile navigation, and newsletter feedback.

## Prompt 3 — Testing and improvement
**Prompt:**  
"Review this landing page against these checks: navigation, category filters, product interactions, newsletter form, mobile layout, image alt text, keyboard accessibility, and horizontal overflow. Identify likely issues and suggest small fixes without adding frameworks or unnecessary complexity."

**Outcome:**  
The implementation includes aria labels and pressed states for filters, a mobile navigation toggle, image alternative text, responsive grid breakpoints, and status messages for demo interactions. Manual browser testing is still required before submission.
