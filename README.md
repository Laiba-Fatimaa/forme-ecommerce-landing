# FORME — Ecommerce Landing Page

A responsive, single-page ecommerce landing page created for the Looponics Student Practical Challenge.

## Features
- Full-width photographic hero with centered text and call-to-action
- Sticky navigation and responsive mobile menu
- Brand introduction and product collection
- Category filters (All, Wear, Carry, Living)
- Demo add-to-bag counter and total
- Newsletter signup confirmation
- Responsive desktop and mobile layouts

## Built with
- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- Unsplash images

## Run locally
1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`, or use the Live Server extension in VS Code.

No package installation or build step is required.

## Important note
This is a front-end student demonstration. It does not process real payments, store cart data, or send newsletter emails.

## Project files
- `index.html` — page structure
- `style.css` — layout and responsive styling
- `script.js` — category filters and demo interactions
- `project-plan.md` — project planning
- `prompts.md` — AI prompts and outcomes
- `testing-report.md` — test plan and manual checks
