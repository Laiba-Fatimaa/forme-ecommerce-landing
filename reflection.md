# Reflection

This project helped me understand how AI can support the process of planning and building a website. I used prompts to define the website structure, choose a visual direction, and generate a starting point for the HTML, CSS, and JavaScript. I learned that a good landing page needs more than attractive images: its navigation, product layout, readability, and mobile experience also matter. One challenge was keeping the design visually consistent while making the category filters and other interactions work. I addressed this by separating the page structure, styling, and JavaScript into different files. If I continue this project, I would connect the demo cart to a backend, add product detail pages, and integrate a real newsletter service and secure checkout.
