# Project Plan — FORME Ecommerce Landing Page

## 1. Project idea
FORME is a fictional lifestyle ecommerce brand. The website is a single-page storefront that introduces the brand and lets visitors browse a small collection of demo products.

## 2. Problem and purpose
Online shoppers need a clear, attractive way to discover products. This landing page presents products in an organized layout and makes category browsing simple.

## 3. Target audience
People interested in minimal clothing, accessories, and home essentials.

## 4. Goals
- Create a visually appealing ecommerce landing page.
- Make navigation clear and predictable.
- Let users filter products by category.
- Demonstrate a simple add-to-demo-bag interaction.
- Make the page usable on desktop and mobile.

## 5. Planned sections
1. Navigation bar
2. Hero section with background image, centered headline, short description, and call-to-action
3. Brand introduction
4. Product collection with category filters
5. Brand feature banner
6. Newsletter signup and footer

## 6. Features
- Anchor navigation links
- Responsive mobile navigation
- Category filters: All, Wear, Carry, Living
- Demo add-to-bag counter and total
- Newsletter form confirmation (front-end demo only)
- Smooth scrolling and image alt text

## 7. Visual direction
- Style: minimal, editorial, modern lifestyle store
- Colors: warm off-white (#f7f5f0), charcoal (#22231f), muted brown (#9b654d)
- Typography: Playfair Display for headings; DM Sans for body text
- Layout: generous whitespace, large photography, simple product grid

## 8. Tools
- HTML5, CSS3, JavaScript
- ChatGPT for planning, prompt development, code assistance, and review
- VS Code for editing
- GitHub for source control
- GitHub Pages or Netlify for deployment

## 9. Scope and limitations
This is a front-end student demo. It does not process payments, save orders, send newsletter emails, or connect to a product database. Product photos are loaded from Unsplash and therefore require an internet connection.
